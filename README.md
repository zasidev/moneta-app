# Expenses Tracker Hub

Voglio creare un progetto per gestire le spese personali collegandomi ai conti bancari tramite openbanking con la sandbox GoCardless: imposta il collegamento di test e integra il flusso di autorizzazione e sincronizzazione.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
